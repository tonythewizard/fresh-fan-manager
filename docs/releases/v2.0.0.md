Fresh Fan Manager 2.0.0 introduces a modular Linux hardware dashboard, adaptive cooling backends and a headless thermal watchdog.

## Highlights

- Twelve reorderable cards for CPU, fans, memory, GPU, power, network, storage and maintenance.
- Essentials and All Widgets views, six themes, a temperature-aware tray icon and a floating mini monitor.
- Eleven selectable UI languages, with English as the default and fallback.
- Implemented cooling backends for ThinkPad ACPI, ASUS WMI, Dell thermal profiles, Apple SMC, mbpfan and generic hwmon PWM, subject to the device's kernel interfaces.
- Optional release checks with a title-bar indicator, Markdown notes and package links.

## Reliability and security

- Manual-control watchdog handles high or missing CPU temperature and reports failed return-to-auto commands.
- Stress-test cancellation terminates child workers; thermal limits stop the workload.
- Privileged helpers validate controller identifiers and load the native SMC library only from a trusted installation.
- User cache cleanup runs without root permissions.
- Vertical resizing uses actual card geometry, with all 4,096 visibility combinations checked locally.

## Downloads

Choose the native package matching your distribution and architecture:

- **Debian / Ubuntu:** `fresh-fan-manager_2.0.0_amd64.deb`
- **Arch / CachyOS / Manjaro:** `fresh-fan-manager-2.0.0-1-x86_64.pkg.tar.zst`
- **Fedora / compatible RPM systems:** `fresh-fan-manager-2.0.0-1.fc44.x86_64.rpm` (built on Fedora 44)
- **Python:** wheel and source distribution. Python-only installations do not install the privileged system integration.

`SHA256SUMS` contains checksums for the attached artifacts. An RPM debuginfo package may also be included for debugging.

See the [README](https://github.com/tonythewizard/fresh-fan-manager/blob/v2.0.0/README.md) for screenshots, installation, hardware requirements and usage.

## Validation scope

The local regression suite covers 39 tests, Qt scales of 100%, 125% and 150%, and exhaustive card-visibility geometry. Local read-only telemetry was exercised on a macsmc system. Physical fan-control writes across every vendor, ARM builds and all Linux desktop sessions have not been certified. Platform support depends on the kernel interfaces exposed by each machine.
