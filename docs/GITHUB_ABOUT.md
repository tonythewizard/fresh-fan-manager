## Extended project description

Fresh Fan Manager combines hardware telemetry and cooling controls in a compact,
configurable Linux desktop application. Its twelve modular cards cover CPU, fans,
memory, GPU, power, network, storage and maintenance. It supports six themes,
eleven selectable languages, tray and floating mini monitors, plus a headless
thermal watchdog. Cooling backends adapt to supported ThinkPad, ASUS, Dell,
Apple SMC, mbpfan and generic hwmon PWM interfaces, with read-only monitoring on
other systems. Source installation and Debian, Arch and RPM build paths are provided.

Compatibility depends on the kernel interfaces exposed by each device. The README
includes the hardware requirements, distribution routes and actual validation scope.
